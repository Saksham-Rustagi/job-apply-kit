## How to read this

- **Every link was checked open on 2026-11-24** (ATS API, an HTTP read of the posting page, or a browser render). Postings close fast, so open the link and confirm before you spend time on an application.
- **Pay** is what the posting publishes. Blank = not published (never estimated).
- **Sponsorship** comes from each posting's own text:
  - **Yes** = the posting says it sponsors visas.
  - **Not stated** = the posting neither offers nor rules out sponsorship; ask the recruiter.
  - **Unclear** = ambiguous wording (e.g. the application form asks about sponsorship, or clearance may be needed); see the evidence column in `jobs.csv` / `jobs.xlsx`.
  - **No - posting says no sponsorship** = the posting states it will not sponsor.
  - **No - US citizen / green card / clearance only** = US citizenship, permanent residency, a security clearance, or US-person export-control status is required.
- Full details (sponsorship evidence, level signal, experience/degree notes, verification method) are in `jobs.csv`, `jobs.xlsx` and `jobs.json`.
